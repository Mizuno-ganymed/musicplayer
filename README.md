# Qobuz DLNA Player

Qobuz の音楽を検索して、家の DLNA レンダラー（ネットワークオーディオ、AV アンプなど）へ送って再生するシンプルなプレイヤーです。
PC で起動し、ブラウザの画面から操作します。依存パッケージはありません（Node.js 20 以上のみ）。

## 使い方

```bash
npm start
```

ブラウザで http://localhost:8080 を開き、次の順に操作します。

1. **ログイン** — Qobuz の App ID / App Secret と、メールアドレス・パスワード（または `user_auth_token`）を入力
2. **再生先を選択** — 右上のプルダウンから DLNA レンダラーを選ぶ（出てこないときは「再検索」、それでも駄目なら description URL を手動で追加）
3. **検索して再生** — 曲をクリックするとその曲から、アルバムを開いて「アルバムを再生」で全曲をキューに入れて再生

曲が終わると自動で次の曲を送ります。再生／一時停止、前後の曲、シーク、音量、音質（MP3 320k 〜 FLAC 24bit/192kHz）を画面から操作できます。

## 設定

| 環境変数 | 既定値 | 内容 |
| --- | --- | --- |
| `PORT` | `8080` | 待ち受けポート |
| `LAN_UI` | なし | `1` にすると、同じ LAN 内のスマホなど他の端末からも画面を操作できる |

ログイン情報（App ID / Secret / トークン。パスワードは保存しません）と選択中のレンダラーは `config.json` に保存されます。このファイルは Git 管理外です。

## 仕組み

```
ブラウザ ──操作──▶ このアプリ ──SOAP (AVTransport)──▶ DLNA レンダラー
                     ▲   │                                  │
                     │   └──検索・配信URL取得──▶ Qobuz API   │
                     └────────── /stream/… を取りに来る ◀────┘
```

- レンダラーの探索は SSDP、操作は UPnP AVTransport / RenderingControl です。
- レンダラーには Qobuz の URL を直接渡さず、このアプリが HTTP で中継します。HTTPS や長い署名付き URL を扱えないレンダラーでも再生できるようにするためです。そのため、再生中はこのアプリを起動したままにしてください。
- 画面と API は既定ではこの PC からしか使えません。ストリーム用 URL だけは LAN に公開されますが、キューに入れた曲ごとのランダムなトークンが無いと取得できません。

## 注意

- Qobuz の App ID / App Secret は Qobuz から発行されたものを使ってください。このアプリには含まれていません。
- 契約プランで再生できない曲や音質を選ぶと、30 秒の試聴版になることがあります（画面下に注意が出ます）。
- ギャップレス再生には対応していません（曲の終わりを検知してから次の曲を送ります）。

## テスト

```bash
npm test
```

偽の Qobuz API と偽のレンダラーを使って、ログイン → 検索 → 再生 → ストリーム中継 → 自動曲送りを確認します。
